## 3. ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### 3.1 Проблемы, аналогичные описанным в аудите

1. **Смешанное использование баз данных**:
   - Проблема: Проект пытается использовать и PostgreSQL, и SQLite одновременно
   - Решение: Унифицировать использование одной БД (рекомендуется PostgreSQL для production)

2. **Отсутствие единой системы DI**:
   - Проблема: Используются статические методы вместо инъекции зависимостей
   - Решение: Реализовать DI через FastAPI `Depends()` для сервисов

3. **Недостаточная обработка ошибок**:
   - Проблема: Нет единой системы кастомных исключений
   - Решение: Создать базовые классы исключений и глобальные обработчики

### 3.2 Уникальные проблемы текущего проекта

1. **Конфликт импортов БД**:
   - В `app.py` одновременно импортируются `database` (SQLite) и `db.postgres.engine`
   - Это вызывает ошибки при запуске, если PostgreSQL не доступен

2. **Отсутствие документации API**:
   - Нет OpenAPI/Swagger документации
   - Сложно понять доступные endpoints и их форматы
