## 🛠 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Текущая архитектура:
- **Backend**: FastAPI (Python 3.12) на порту 8001
- **Frontend**: React + Vite + Tailwind CSS (собранный в `dashboard/frontend/dist/`)
- **База данных**: PostgreSQL на порту 5433
- **Аутентификация**: JWT с middleware
- **Сервер приложений**: Gunicorn + Uvicorn

### Состояние системы:
- **Backend**: Запущен и отвечает на запросы
- **Frontend**: Собран, но не обслуживается backend'ом
- **База данных**: Конфигурация настроена, требуется проверка подключения
- **AI интеграции**: Конфигурация настроена, требуется тестирование
