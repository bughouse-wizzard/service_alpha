## 1. Обзор системы

### 1.1 Архитектура проекта
Проект имеет следующую структуру:
- `agents/` - AI-агенты (coder, tester, base)
- `llm/` - интеграция с LLM провайдерами
- `vcs/` - интеграция с системами контроля версий (GitHub, GitLab, Gitea)
- `integrations/` - интеграции с Jira, Telegram
- `schemas/` - схемы данных (Pydantic модели)
- `dashboard/` - веб-интерфейс (frontend + backend)
- `db/` - работа с базами данных (PostgreSQL)
- `bot/` - основной бот-оркестратор

### 1.2 Основные файлы реализации
- `main.py`, `main_v2.py`, `main_integrated.py` - основные точки входа
- `planner.py`, `planner_v2.py` - планировщик задач
- `worker_orchestration.py` - оркестрация воркеров
- `agents/coder.py`, `agents/tester.py` - агенты для генерации кода и тестов
