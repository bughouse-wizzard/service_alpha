### Задача 1.3: Создание публичных health checks
**Цель**: Добавить публичные эндпоинты для мониторинга
**Сложность**: Низкая
**Ожидаемое время**: 3-6 часов

**Шабы**:
1. Открыть `dashboard/backend/app.py`
2. Добавить новый роутер для health checks
3. Создать эндпоинты:
   - `GET /health` - базовая проверка
   - `GET /health/db` - проверка подключения к БД
   - `GET /health/redis` - проверка Redis

**Пример кода**:
```python
@app.get("/health")
async def health_check():
    return {"status": "healthy", "timestamp": datetime.now()}

@app.get("/health/db")
async def db_health_check():
    # Проверка подключения к БД
    pass
```

**Критерии успеха**:
- Эндпоинты доступны без аутентификации
- Возвращают корректный JSON
- Показывают реальный статус системы
